Rebonds : durs, doux et que faire de chacun

Comment lire un rebond, ce qui distingue les types et quand supprimer un contact de votre liste.

Par María Luisa Duque · Email Deliverability Manager · Mis à jour 2026-11-14

Dans ce guide

  2. Rebonds durs

Qu'est-ce qu'un rebond

Un rebond est la réponse d'un serveur qui n'a pas pu remettre votre email. Il contient toujours un code : un code de base à trois chiffres (comme 550) et, généralement, un code étendu (comme 5.1.1). Le premier chiffre dit presque tout : 4 est temporaire et 5 est permanent.

Rebonds durs

Ils sont permanents : la boîte n'existe pas (5.1.1), le domaine n'existe pas (5.1.2) ou le compte est désactivé (5.2.1). La seule bonne réponse est de supprimer l'adresse immédiatement. Continuer à écrire à des adresses inexistantes est l'un des signaux qui nuisent le plus à la réputation.

Rebonds doux

Ils sont temporaires : boîte pleine (4.2.2), serveur saturé, greylisting ou limites de débit (4.7.0). Votre plateforme réessaie. Si une adresse rebondit en doux sur 3 à 5 envois consécutifs, traitez-la comme un rebond dur.

Les blocages : le troisième type

Beaucoup de rebonds en 5.7.x n'ont rien à voir avec le destinataire : le serveur vous refuse pour votre réputation, une liste noire ou un domaine non authentifié. Dans ce cas, ne supprimez pas le contact, corrigez le problème. Si vous les classez comme rebonds durs, vous finirez par supprimer de bonnes adresses.

Chiffres de référence

  • Taux de rebond total par envoi : sous 2 %.
  • Rebonds durs : idéalement sous 0,5 %.
  • Si un envoi dépasse 5 %, arrêtez et vérifiez la liste avant de continuer.

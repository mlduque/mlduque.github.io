Come uscire da Spamhaus: SBL, CSS, XBL, PBL e DBL

Cosa significa ogni lista di Spamhaus, come capire in quale sei, quali puoi rimuovere da sola e cosa fare per non rientrarci.

Perché Spamhaus è così importante

Spamhaus è l'organizzazione di blacklist più usata al mondo. Migliaia di provider di posta e aziende consultano le sue liste prima di accettare un'email. Se il tuo IP o il tuo dominio compaiono lì, molti dei tuoi invii rimbalzeranno con messaggi che citano spamhaus.org.

Non è una sola lista: sono diverse, e ognuna si risolve in modo diverso. Il primo passo è sapere in quale sei.

Le liste, una per una

  • SBL: IP che Spamhaus collega allo spam o a mittenti con cattiva reputazione. È la più seria e la esamina una persona.
  • CSS: IP che inviano posta con problemi tecnici o di qualità: HELO errato, DNS inverso generico, contenuti tipici dello spam. È la più frequente per server legittimi mal configurati.
  • XBL: IP di computer infetti, proxy aperti o server compromessi.
  • PBL: intervalli di IP che il proprietario stesso (per esempio un provider internet domestico) dichiara non dovrebbero inviare posta direttamente. Non è una punizione, è una politica.
  • DBL: domini, non IP. Elenca domini usati per spam o phishing, compresi quelli dei link nelle tue email.

Scopri dove sei

  1. Vai sul verificatore ufficiale di Spamhaus, check.spamhaus.org.
  2. Inserisci l'IP del tuo server di invio o il tuo dominio.
  3. Ti dice in quale lista sei, da quando e spesso il motivo.

Puoi anche controllare IP e dominio in Informazioni su un IP e in Il mio dominio, che consultano più liste insieme.

Come uscire da ogni lista

  • CSS e XBL: di solito puoi chiedere la rimozione da sola dal verificatore di Spamhaus. Prima risolvi la causa: un HELO con un nome reale, un DNS inverso proprio che punti all'IP e verifica che l'IP non invii spam da un computer infetto. Se non lo risolvi, rientrerai.
  • PBL: se il tuo IP è di un intervallo domestico, la cosa giusta è inviare tramite il server del provider o una piattaforma di invio, non direttamente. Se è il tuo vero server di posta, con IP fisso e DNS inverso proprio, puoi chiedere la rimozione dalla PBL dal verificatore.
  • SBL: la esamina una persona di Spamhaus. Di solito deve contattarli il proprietario dell'IP (il tuo hosting o la tua piattaforma di invio) spiegando cosa è stato corretto.
  • DBL: controlla i domini dei tuoi link e del mittente. Se un dominio era compromesso, puliscilo e chiedi la rimozione dal verificatore.

Perché si finisce in Spamhaus senza essere spammer

  • Inviare a liste vecchie o acquistate che contengono spam trap.
  • Un server che si presenta con un HELO errato o senza DNS inverso proprio.
  • Un modulo web non protetto che i bot usano per inviare spam dal tuo server.
  • Un computer o un account email aziendale infetti.
  • Condividere l'IP con altri clienti che fanno spam.

Leggi la guida HELO, PTR e NAT per capire i requisiti tecnici che Spamhaus controlla.

Checklist

  • ☐ So in quale lista sono (SBL, CSS, XBL, PBL o DBL).
  • ☐ Ho trovato e corretto la causa.
  • ☐ HELO e DNS inverso corretti.
  • ☐ Ho chiesto la rimozione (io stessa o il mio provider, a seconda della lista).
  • ☐ Tengo d'occhio IP e domini per sapere se rientro.
